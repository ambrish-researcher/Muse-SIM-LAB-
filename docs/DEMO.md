1. Open the intro. Move the pointer, click the core to pulse it and scroll to arc the camera. Enter SimLab. The gateway contains abstract geometry and a central prompt, with no lab previews.
2. Submit “construct Muse Wonder and explain attention” or select Wonder. Watch the empty stage become a 22-component system. Experiment opens automatically. Change the text and query, inspect tensors, retrieve/add memory, then step the agent through its controlled failure and approval.
3. Return to the gateway and build MTIA 400. Inspect its 20 construction stages, explode/isolate components, then edit A[1,1] from 1 to 2: C becomes `[24,28;43,50]`. Run MAC operations, compare quantizer settings, and use Inspect → Rack infrastructure for the illustrative 72-tray context.
4. Build Robot Max. Its 32 stages include separately introduced left and right hips. Inspect the detailed rig, then run the autonomous task. Add an obstacle through the 3D floor or accessible grid and observe replanning. The gripper follows IK and the cube follows the hand only after a checked grasp. Inspect placement and failure scenarios.
5. Results downloads the current computed state. Reset experiment restores its inputs. Restart construction removes all lab geometry and rebuilds from zero. Return to the gateway without replacing the Canvas.

Normal construction lasts roughly 35 seconds for Wonder, 32 seconds for the chip and 51 seconds for the robot, plus travel/loading. Reduced motion still introduces every stage separately with direct placement, in approximately 8–12 seconds. Set it in Experience settings before launching. There is no playback speed or timeline.
