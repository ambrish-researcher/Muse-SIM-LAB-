# Decisions

1. Replace the page/card prototype with one persistent full-window Canvas and HTML accessibility layer. Use a single camera director; OrbitControls owns the camera only in free inspection.
2. Keep trustworthy numerical primitives and regression tests. Add a complete tiny transformer and deterministic robotics task snapshots instead of extending frame-driven state.
3. Author procedural assets without purchased CAD. Use layered physical materials, detailed fingers/actuators/cables, dense regular microstructures and instancing. All unpublished geometry is illustrative.
4. Keep GSAP for cinematic choreography. Motion MCP was tested for accessibility guidance; adding a second motion runtime is unnecessary.
5. Use Node's HTTP server for a minimal deployable same-origin backend, Zod for boundaries and schema validation. Without a supplied key, live inference remains unverified and zero paid requests are made.
6. Key, verified pricing and explicit user approval of a paid test are required before inference. The approval flag defaults false. Reserve a conservative maximum request charge; never equate app spend with account balance. Ledger must persist if deploying beyond a local demo.
7. The final construction request replaces chapter playback with 22/20/32 component sequences. Pending geometry is unmounted, introduced geometry enters its parent-local anchor, and attached geometry remains. Inspection and numerical execution are separate concerns. Reduced motion preserves sequence with direct placement.
8. Gateway routing is deterministic and local. Both form submission and textual suggestions call one launch action; no lab model or preview is mounted there. Scene launch does not request optional narration.
9. Component reference levels follow the selected or active part. Actual intermediate tensors and task state drive diagrams and motion; geometric camera interpolation does not mutate numerical state. Graphics/model readiness gates construction so slow module loading cannot skip its opening.
